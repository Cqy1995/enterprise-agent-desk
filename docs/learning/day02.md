## 最小分类评测练习

```bash
npm run learn:eval
```

04-evaluate-classification.mjs使用五条手工构造的输入、人工预期类别与固定答案，不联网。原始版本前三条输出合规且类别正确，第四条合规但类别错误，第五条question类型错误。

预期统计：输出合规率4/5=80%；端到端分类通过率3/5=60%。后一指标要求输出合规且类别正确；两项分母都为全部样例。不合规结果不会被移出分母，也不能因为category文本看起来正确就计为端到端通过。

指标中的“合规”包含语法、字段类型/枚举及字段关联约定。本练习不判断澄清问题的语义质量，不代表真实模型准确率。脚本输出评分而不是要求全部错例消失，因此出现错误样例但正常退出，不等同于上一练习expected与accepted不一致导致的测试失败。

本人已将第四条actualContent改为正确类别并提供修改前后截图：输出合规率保持80%，端到端分类通过率从60%变为80%。该实验验证计分逻辑，不代表模型得到优化。固定答案练习文件保留本人修改。

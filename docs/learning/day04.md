## 11月3日本地演示

新增tool-loop.mjs可复用控制逻辑、08-tool-loop-demo.mjs预设模型响应。默认最多3次模型请求、2次工具函数调用，每轮一个getTicket。最后一轮仍要求工具时停止，不执行这次工具，不添加额外总结请求。记录模型请求与工具执行两个计数。

```bash
npm run learn:loop -- normal
npm run learn:loop -- repair
npm run learn:loop -- repeated
npm run learn:loop -- budget
npm run learn:loop -- not_found
```

不读Key、不联网，模拟的是模型回复，不是模拟getTicket函数：工具仍执行当前本地模拟工单查询。normal预期2次模型请求、1次工具函数调用、completed。校验不通过也占一次工具函数调用；JSON解析失败则不进入工具函数。
